Test parts continue to the next cell. Three consecutive OOM cells stop the part with stopped_mechanical_oom; a successful cell resets the streak. It forces exactly 1024 new greedy tokens, ignoring EOS, to test the full output allowance. These are synthetic speed inputs, not evaluation episodes. After the first OOM, the SAME loaded model re-runs the 2500-token rung and journals recovery_check with fit/OOM, peaks, retained IDs and equality to its first pass. It then sends a public oversize prompt through evaluation generation_functions itself, journalling evaluation_oom_probe. The probe uses the first failed rung capped at 15360 tokens, plus the normal 1024 output allowance, to avoid preempting CUDA allocation with the context guard. It may fit: the event reports the observed outcome without claiming an OOM was exercised when none occurred. The ladder then stops climbing; the other backend is still attempted. Later unattempted lengths have no invented fit status. Handled interruption retains events, metadata and manifest.
