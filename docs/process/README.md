# Working notes

These are working notes from building TAA Lab with AI assistants: handoffs between sessions,
review notes, and study plans written as prompts. Each assistant is identified by a working name.
The notes are kept for transparency about how the lab was built, as the papers' AI-use disclosures
describe. They are not part of the evidence. The dated predictions and results are in
`LAB_NOTEBOOK.md`, and the run records are in `results/`.

These files were moved here from `docs/` on 2026-09-28, so older notebook entries may refer to
their earlier paths.
