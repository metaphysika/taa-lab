# Results

Each run writes a folder here. After a model run, rename it:

    YYYY-MM-DD vX.Y <agent>-<counsel> r<repeats> [note]

for example `2026-09-25 v0.4 claude-claude r3`, commit it, and add an entry to `LAB_NOTEBOOK.md`.
Keep every run, including failures. These folders are the evidence behind any claim about TAA.
Unnamed timestamp folders are runs nobody has reviewed yet.
